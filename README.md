# Node.js Design Patterns

## Currently Studying

I'm currently studying and upgrading my skills by reading **Node.js Design Patterns** (Mario Casciaro & Luciano Mammino). This repository holds my notes and hands-on experiments as I work through the book.

## What I'm Covering

- **Node.js platform fundamentals**: the event loop, the reactor pattern, and the module system
- **Callbacks and events**: continuation-passing style, `EventEmitter`, and the observer pattern
- **Asynchronous control flow**: Promises, `async/await`, and avoiding callback hell
- **Streams and Buffers**: processing data efficiently, piping, and backpressure
- **Creational patterns**: factory, builder, revealing constructor, and dependency injection
- **Structural patterns**: proxy, decorator, and adapter
- **Behavioral patterns**: strategy, state, template, middleware, and command
- **Scaling and architecture**: clustering, worker threads, and microservice basics

## Repository Layout

- `0_yr_25/`: code and notes from 2025 (Buffers, async, Express, and more)
- [`ch2_module_sys/`](ch2_module_sys): Chapter 2, the module system (revealing module, CommonJS vs ESM, live bindings, circular dependencies, dynamic `import()`, TypeScript notes)

## Goal

Move beyond just making things work. The aim is to write Node.js code that is scalable, maintainable, and idiomatic by applying proven design patterns.
